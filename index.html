01 — Brief

案件: 高級割烹のランディングページ

業態

高級レストラン／割烹。日本料理・コース中心、ディナー主体で客単価高め。

ターゲット

記念日・接待・会食でハレの日の店を探す 30〜60代。質と静謐な空間を重視する層。

目的（主CTA）

来店を促す。営業時間・アクセス・地図を見やすく示し『行ってみたい』と思わせて足を運ばせる。予約は副次的な導線として用意。

トンマナ

上品・ラグジュアリー。余白を贅沢に取り、静謐で落ち着いた高級感。和の格式と信頼感。

ブランドカラー

指定なし（おまかせ）。和の高級感に合う配色をアートディレクションで提案。墨黒・生成り・金／銅、深い藍・漆・苔色など。安易な赤一色は避け、上質なティント設計で。

コピー言語 / 想定セクション

日本語（和文組版に配慮。palt・行間・行長を丁寧に）。ヒーロー（料理または店構え）を起点としたセクション構成。

02 — Adjudication

審査結果と勝者の選定

3つのアートディレクションを visual / ux / a11y の3レンズで審査。僅差ながら、没入のシアター性とCTAの強度で〈漆黒弁柄〉が総合首位となりました。

Why the winner

勝者の選定理由 — 〈漆黒弁柄〉

visual 81 を筆頭に、没入ダークの闇が料理と店構えを舞台のように際立たせ、ハレの日の特別感を最も強く喚起しました。弁柄の灯と燻し金のヘアラインが格式と緊張感を両立し、主CTA「行ってみたい」への視線誘導も明快。a11y は3案中で要改善点を最も多く抱えていましたが、その指摘はいずれも色トークンの調整で解消可能と判断し、総合77.7点で採用。続く磨き込みフェーズで指摘に対応し、 93点まで引き上げました。

04 — Refinement

磨き込みで対応した主な指摘

審査で挙がった指摘を critical / major で整理し、それぞれ修正を反映。とりわけ予約導線の実体化と、没入ダークで犠牲になりがちな可読性（コントラスト）を最優先で是正しました。

critical

最終CTAブロックとstickyバーの主CTA「ご予約」が、実体のある予約フォームではなく #reserve アンカー（説明文と電話・メールの繰り返し）に着地。コピーは「フォームより承ります」と謳うがフォームが存在せず、期待と現実が食い違う（Nielsen #2 一致／#1 可視性）。客単価2万円超・完全予約制で電話受付が 11:00–20:00 に限定され、時間外の来訪者は予約手段を失う致命的離脱。

→ 修正：#reserve 内に実体ある予約フォーム（来店日・時間帯 select、人数 stepper、コース選択ラジオ、用途／アレルギー textarea、氏名・電話・メール）を設置、または外部予約（OMAKASE／TableCheck 等）の実URLを btn-bengara に割当。stickyバーの href も同フォーム／外部URLへ。未実装の間は文言を「お電話・メールにて承ります」に修正して期待を一致。

critical

tint #8C7F72 を本文・説明文の常用色に使用していたが、墨地で 4.83:1、パネル地で 4.34:1 と AA 4.5:1 を割る。コース献立の品名、コンセプト2段落目、各カード説明文、アクセス補足などサイト全体の「読ませる」テキストの大半がこの色。tan 地では明確に AA 不適合で、小サイズ（0.84〜0.92rem）が重なり実害が大きい。

→ 修正：tint をボディ用に明度を上げ --color-tint #A89A8B（tan 約5.6:1／sumi 約6.3:1）。装飾ラベル専用に従来の #8C7F72 を --color-tint-muted として分離。

critical

半透明 tint の派生色が判読不能レベル。縦書き「昼／夜」ラベル text-tint/40 は tan 地で 1.77:1。コピーライト text-tint/60 は 2.50:1、各種注記 /70・/80 は 2.97〜3.26:1。料金注記・キャンセル規定など実務上重要な情報が読みにくい。

→ 修正：注記・コピーライトの最低を AA 4.5:1 に。/70・/80 は不透明な明色（#9A8C7D 以上、tan 約4.6:1）へ置換。縦書き「昼／夜」は不透明 #8C7F72（約4.3:1）か kin/50 程度へ。装飾と明示する場合は aria-hidden + hidden md:inline でSR除外を宣言。

major

本文 line-height が body 全体で 1.8、各 leading で 1.9–1.95。weight 300 の生成り細字に対し 1.95 は緩みすぎで、明朝見出しの密度との落差からシアターの緊張感を削ぐ。特に concept の 1.16rem 本文。

→ 修正：長文ブロックの leading を 1.78 に統一、body の line-height を 1.8 → 1.72。短文リストは 1.7 で据え置き可。

major

本文ウェイト 300 + tint #8C7F72 の組み合わせがコントラスト不足。sumi 地で約 4.1:1、0.84–0.92rem の補足テキスト（品名・注記・access 小字）で AA を下回る。没入ダークの代償として可読性が犠牲に。

→ 修正：補足テキスト用 tint を #9D9082（約5.2:1）へ、または font-weight を 300→400。料理品名は #A89A8B に。最重要本文は #E8DECF を維持。

major

数字書体 Cormorant（weight 300）が価格 ¥8,800 / ¥22,000 の 2.6rem で細く頼りない。最重要コンバージョン要素の価格が明朝見出しに視覚的重量で負け、視覚階層の主役になれていない。Webフォント未読込時の serif フォールバックも数字幅が不揃いになるリスク。

→ 修正：.num を weight 300→400、letter-spacing 0.02em→0.01em、font-feature-settings: 'tnum' 1 で等幅数字化。¥記号と数値の間の全角スペースは margin-right: 0.12em の span 制御に。
